About the Project

The Student Performance Prediction System is designed to assist students and educators in analyzing academic performance. Using Machine Learning and Data Science, it predicts scores, grades, and pass/fail status while providing useful visual insights.

Key Features

  • 📊 Performance Prediction: Enter study details and instantly get predicted scores and grades.
  • 📈 Dashboard: Filter and track academic progress with tabular data.
  • 📉 Graphical Insights: View interactive charts built with Chart.js for better understanding.
  • 🔒 Authentication: Secure login and signup with CRUD operations.

How It Works

  1. Users enter details like hours studied, attendance percentage, assignments submitted, and previous grades.
  2. The trained ML model processes the data and predicts the performance score.
  3. The system displays grade, pass/fail status, and graphs for deeper insights.

Technology Stack

Our project is built using the following technologies:

  • Frontend: HTML, CSS, Bootstrap
  • Backend: Flask (Python)
  • Database: SQLite (lightweight, integrated)
  • ML & Visualization: Scikit-learn, Pandas, Chart.js

Future Scope

We plan to extend the system with advanced features such as:

  • 📱 Mobile application integration for real-time updates.
  • 🤖 Personalized study recommendations using AI.
  • 📡 Real-time data streaming for live performance tracking.
